# xHelper-for-ADB-
XHelper α‑1.0.1 LTS/ATS — это GUI‑утилита на PyQt6 для управления Android‑устройствами через ADB. Приложение объединяет более двадцати вкладок: установка/удаление APK, массовая установка, push/pull файлов, работа с Fastboot, скринкаст (scrcpy), запись экрана, мониторинг, логкат, тестирование приложений,плагины, бэкапы и скриптовый редактор.
