# xHelper 2.0 Release

**xHelper** — графическая утилита на Python/PyQt6 для повседневной работы с Android-устройствами через ADB и fastboot. Версия **2.0** переводит проект из статуса ранней тестовой сборки в release-сборку без добавления радикально нового функционала: основной упор сделан на стабильность, предсказуемость поведения, документацию и удобство сопровождения плагинов.

## Что улучшено в 2.0

- Обновлено название и версия приложения: теперь окно запускается как `xHelper 2.0 Release`.
- Добавлена единая конфигурация `~/.xhelper_config.json` с путями к `adb` и `fastboot`.
- Улучшен общий запуск ADB-команд: команды разбираются через `shlex`, поэтому пути и аргументы с пробелами обрабатываются корректнее.
- Добавлен публичный API для плагинов: `adb_executable()`, `fastboot_executable()`, `get_selected_device_id()`, `build_adb_args()` и `run_adb_capture()`.
- Загрузка плагинов стала предсказуемой: файлы загружаются в отсортированном порядке, служебные Python-файлы с `_` в начале пропускаются, ошибка одного плагина не блокирует остальные.
- Старое предупреждение ранней сборки заменено на информационный release-диалог.
- Актуализирована документация по запуску, требованиям, безопасной работе и разработке плагинов.

## Возможности

- Просмотр подключённых Android-устройств.
- Выполнение ADB-команд для выбранного устройства или группы устройств.
- Установка, удаление и запуск APK/пакетов.
- Массовая установка APK из папки.
- Операции с файлами через `adb push` / `adb pull`.
- Logcat, тестирование приложений и сбор диагностической информации.
- Скриншоты, запись экрана и запуск scrcpy при наличии установленного `scrcpy`.
- Бэкап/восстановление и отдельная вкладка fastboot.
- Плагинная система для расширения интерфейса без изменения ядра.

## Требования

- Python 3.10+.
- PyQt6.
- Android Platform Tools (`adb`, `fastboot`) в `PATH` или путь к ним в настройках `~/.xhelper_config.json`.
- Для зеркалирования экрана — установленный `scrcpy`.
- На Android-устройстве должна быть включена отладка по USB.

## Быстрый запуск

```bash
python -m pip install PyQt6
python "xHelper 2.0 Release.py"
```

> Основной файл теперь также называется как релиз: `xHelper 2.0 Release.py`.

## Автоматическая установка на ПК

Для локальной установки xHelper 2.0 Release для текущего пользователя запустите большой установочный скрипт из корня проекта:

```bash
python install_xhelper_2_0.py
```

Скрипт автоматически:

- создаёт виртуальное окружение `.venv-xhelper-2.0`;
- устанавливает PyQt6;
- создаёт запускатель `run_xhelper_2_0_release.bat` на Windows или `run_xhelper_2_0_release.sh` на Linux/macOS;
- пытается создать ярлык на рабочем столе пользователя;
- проверяет наличие `adb`, `fastboot` и `scrcpy` в `PATH` и выводит подсказки, если их нет.

> Android Platform Tools не распространяются вместе с проектом. Если `adb`/`fastboot` не найдены, установите их отдельно или укажите путь в `~/.xhelper_config.json`.

## Конфигурация

При запуске приложение читает файл:

```text
~/.xhelper_config.json
```

Пример:

```json
{
  "adb_path": "adb",
  "fastboot_path": "fastboot",
  "theme_dark": false
}
```

Если файла нет, используются значения по умолчанию.

## Безопасность

xHelper выполняет реальные ADB/fastboot-команды. Перед удалением файлов, прошивкой, восстановлением или массовыми операциями:

1. Проверьте выбранное устройство во вкладке «Устройства».
2. Убедитесь, что команда относится именно к нужному устройству.
3. Сделайте резервную копию важных данных.
4. Не запускайте команды из непроверенных источников.

## Разработка плагинов

Плагины находятся в каталоге `plugins/`. Каждый файл `*.py` должен экспортировать функцию:

```python
def register(main_window):
    ...
```

Минимальный пример:

```python
# plugins/example.py
from PyQt6.QtWidgets import QLabel, QVBoxLayout, QWidget


def register(main_window):
    tab = QWidget()
    layout = QVBoxLayout(tab)
    layout.addWidget(QLabel("Пример плагина"))
    main_window.tabs.addTab(tab, "Example")
```

Полезный публичный API главного окна:

| API | Назначение |
| --- | --- |
| `main_window.tabs` | Добавление вкладок в основной интерфейс. |
| `main_window.log_message(text)` | Запись сообщения в общий лог. |
| `main_window.log_signal.emit(text)` | Потокобезопасная запись в лог из фоновых потоков. |
| `main_window.settings` | Словарь настроек приложения. |
| `main_window.adb_executable()` | Текущий путь к ADB. |
| `main_window.fastboot_executable()` | Текущий путь к fastboot. |
| `main_window.get_selected_device_id()` | ID выбранного устройства. |
| `main_window.build_adb_args(command, device_id)` | Безопасная сборка аргументов ADB-команды. |
| `main_window.run_adb_capture(command, timeout=30)` | Выполнение ADB-команды с возвратом `CompletedProcess`. |

Рекомендации:

- Не выполняйте долгие операции напрямую в UI-слотах — используйте `QThread` или `threading.Thread`.
- Не используйте `str.split()` для команд с кавычками; используйте API главного окна или `shlex.split()`.
- Логируйте ошибки через `main_window.log_message()`.
- Не меняйте глобальную тему без явного действия пользователя.
- Не храните чувствительные данные в репозитории.
